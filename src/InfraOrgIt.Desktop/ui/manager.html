    Aggiornamenti

    Versione —

    Il controllo legge l'ultima release GitHub. Il download verifica la firma del manifest SHA-256 con la chiave pubblica inclusa nell'app. Solo un archivio elencato nel manifest firmato e con hash corrispondente può essere installato automaticamente: su macOS l'app si sostituisce e si riavvia, sugli altri sistemi si apre la cartella per l'installazione manuale.

    Tunnel

    Accedi con Keycloak per ottenere un token con gli scope mcp:read e tunnels:operate, oppure incolla un token personale. Il token di accesso resta solo in memoria; il token di rinnovo va nell'archivio sicuro del sistema, mai in instances.json o nei log. I target arrivano dall'allowlist dell'istanza.

    Codice:

    Apri la pagina di accesso, conferma il codice e torna qui: i target si caricano da soli.
